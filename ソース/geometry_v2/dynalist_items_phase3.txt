01_arg_sort（偏角：偏角の比較・並べ替え・扇形の中の点の数・角の大きさの比較。整数で厳密）
	説明
		arg_cmp(a, b)（-1 / 0 / 1）/ arg_less(a, b)（sort の比較関数に）/ same_direction(a, b) / arg_half(v)
		arg_sort(ps, 原点 = {0,0}, far_first = false) / arg_sort_idx（番号で）：原点と同じ点が先頭、同じ向きは近い順（far_first なら遠い順）
		arg_sort_from(ps, 原点, 向き) / arg_sort_idx_from：向きから反時計回りに一周する順
		unique_directions(ps, 原点, keep_far) / unique_directions_idx：向きごとに 1 点（近い点 / 遠い点）
		ArgSorted S(ps, 原点)：S.size() / S.order[k] / S.vec[k] / S.zeros / S.lower_bound(dir) / S.upper_bound(dir) / S.groups()
		S.count(l, r, include_l = true, include_r = false)：向き l から反時計回りに r までの点の数（0 度をまたいでよい）/ S.exists(...)
		angle_cmp(a, b, c, d) / angle_less：∠(a, b) と ∠(c, d)（なす角 [0, π]）を誤差なしで比べる
		count_in_open_half(ps, 原点)：各点の左側（偏角が (θ, θ + π)）にある点の数
	メモ
		幾何基盤を同梱済み。偏角は x 軸の正の向きから反時計回りに [0, 2π)。ベクトルの成分は 2×10^9 まで
		原点を含む三角形の数 = C(N, 3) - Σ C(h_i, 2)（h = count_in_open_half。原点を通る直線の上に 2 点が並ばないとき）
		類題：ABC139 F（偏角の順の連続した区間）、ABC225 E（角度の区間を貪欲に。デモに型）、典型90 009 は 06_point_set の max_angle
