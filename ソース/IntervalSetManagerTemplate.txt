// 半開区間 [l, r)。l < r が前提（assert なし）。l >= r の値は「空／該当なし」を表す（Itv{} = {0,0}）。
struct Itv {
    long long l, r;
    constexpr long long len() const noexcept { return r - l; }                         // 長さ
    constexpr long long mid2() const noexcept { return l + r; }                        // 中央値×2（整数のまま比較するため）
    constexpr bool contains(long long x) const noexcept { return l <= x && x < r; }    // x ∈ [l, r)
    constexpr bool empty() const noexcept { return l >= r; }                           // 空（該当なし）か
    constexpr explicit operator bool() const noexcept { return l < r; }                // 空でなければ true
    friend constexpr bool operator==(const Itv& a, const Itv& b) noexcept { return a.l == b.l && a.r == b.r; }
    friend constexpr bool operator!=(const Itv& a, const Itv& b) noexcept { return !(a == b); }
    friend constexpr bool operator<(const Itv& a, const Itv& b) noexcept { return a.l != b.l ? a.l < b.l : a.r < b.r; }  // (l, r) 辞書順
    friend constexpr bool operator>(const Itv& a, const Itv& b) noexcept { return b < a; }
    friend constexpr bool operator<=(const Itv& a, const Itv& b) noexcept { return !(b < a); }
    friend constexpr bool operator>=(const Itv& a, const Itv& b) noexcept { return !(a < b); }
    friend std::ostream& operator<<(std::ostream& os, const Itv& t) { return os << '[' << t.l << ", " << t.r << ')'; }
};
#endif

// =============================================================================
//  ② ItvSet : 区間を add / erase し、重なる区間・隣接する区間を常に結合して管理する集合
// -----------------------------------------------------------------------------
//  区間は半開区間 [l, r)（l < r が前提。高速化のため assert なし）。座標は |値| <= 4e18 程度まで。
//  内部では「互いに重ならず隣接もしない区間」を昇順に保持する（[1,3) と [3,5) は [1,5) になる）。
//  該当なしのときは空区間 Itv{}（= {0,0}）を返す。 if (auto t = s.find(x)) { ... } で判定できる。
//
//  [更新]  add(l, r) / add(t)       [l, r) を追加して結合。結合後の（[l, r) を含む）区間を返す
//          erase(l, r) / erase(t)   [l, r) の部分を削除（区間は切断される）。削除された長さを返す
//          clear()
//  [情報]  size()    区間数        empty()
//          length()  覆われている長さの合計（O(1)）
//          to_vector()  区間を昇順に列挙
//  [判定]  contains(x)        x を含む区間があるか
//          find(x)            x を含む区間（無ければ空）
//          covers(l, r)       [l, r) 全体が覆われているか
//          intersects(l, r)   [l, r) と共通部分を持つ区間があるか（重複判定）
//          next_free(x)       x 以上で覆われていない最小の値（mex は next_free(0)）
//          prev_free(x)       x 以下で覆われていない最大の値
//
//  計算量（n = 区間数, B = ブロック長 128〜。区間数が増えると自動で大きくなる）:
//    add / erase は償却 O(B + log n)、判定系は O(log n)。
//    平方分割 + memmove の実装で、std::map で書いた同機能より約 2 倍速い（n = 5e5, 100 万操作の実測）。
//
//  【使い方】 "template begin" 〜 "template end" の間だけをコピーして使う（main・テスト・デモは貼らない）。
//    4 つのテンプレートを同じファイルに貼っても struct Itv は 1 回だけ定義される（#ifndef ガード）。
//    このファイル単体で実行すると demo()（全機能の使用例）→ random_test()（愚直解との照合）が走る。Release ビルド推奨。
// =============================================================================
class ItvSet {
    struct Pos { int b, i; };                // ブロック番号, ブロック内位置（b == ブロック数 なら末尾の次）
    int bsz_;                                // 目標ブロック長（2*bsz_ に達したら分割。ブロック数が多くなると倍にする）
    int n_ = 0;                              // 区間数
    long long total_ = 0;                    // 長さの合計
    std::vector<std::vector<Itv>> bl_;       // 各ブロック（空ブロックは持たない）
    std::vector<Itv> last_;                  // 各ブロックの末尾要素（l, r ともに単調なので二分探索に使える）

    int nb() const { return (int)bl_.size(); }
    bool is_end(const Pos& p) const { return p.b == nb(); }
    const Itv& at(const Pos& p) const { return bl_[p.b][p.i]; }
    Pos prev(const Pos& p) const { return p.i > 0 ? Pos{p.b, p.i - 1} : Pos{p.b - 1, (int)bl_[p.b - 1].size() - 1}; }

    Pos r_ge_pos(long long x) const {  // 最初の r >= x
        const int b = (int)(std::lower_bound(last_.begin(), last_.end(), x, [](const Itv& a, long long v) { return a.r < v; }) - last_.begin());
        if (b == nb()) return Pos{b, 0};
        const auto& v = bl_[b];
        return Pos{b, (int)(std::lower_bound(v.begin(), v.end(), x, [](const Itv& a, long long y) { return a.r < y; }) - v.begin())};
    }
    Pos r_gt_pos(long long x) const {  // 最初の r > x
        const int b = (int)(std::upper_bound(last_.begin(), last_.end(), x, [](long long v, const Itv& a) { return v < a.r; }) - last_.begin());
        if (b == nb()) return Pos{b, 0};
        const auto& v = bl_[b];
        return Pos{b, (int)(std::upper_bound(v.begin(), v.end(), x, [](long long y, const Itv& a) { return y < a.r; }) - v.begin())};
    }
    Pos l_ge_pos(long long x) const {  // 最初の l >= x
        const int b = (int)(std::lower_bound(last_.begin(), last_.end(), x, [](const Itv& a, long long v) { return a.l < v; }) - last_.begin());
        if (b == nb()) return Pos{b, 0};
        const auto& v = bl_[b];
        return Pos{b, (int)(std::lower_bound(v.begin(), v.end(), x, [](const Itv& a, long long y) { return a.l < y; }) - v.begin())};
    }
    Pos l_gt_pos(long long x) const {  // 最初の l > x
        const int b = (int)(std::upper_bound(last_.begin(), last_.end(), x, [](long long v, const Itv& a) { return v < a.l; }) - last_.begin());
        if (b == nb()) return Pos{b, 0};
        const auto& v = bl_[b];
        return Pos{b, (int)(std::upper_bound(v.begin(), v.end(), x, [](long long y, const Itv& a) { return y < a.l; }) - v.begin())};
    }

    void split(int b) {
        std::vector<Itv> w(bl_[b].begin() + bsz_, bl_[b].end());
        bl_[b].resize(bsz_);
        last_[b] = bl_[b].back();
        last_.insert(last_.begin() + b + 1, w.back());
        bl_.insert(bl_.begin() + b + 1, std::move(w));
        if (nb() > 32 * bsz_) bsz_ *= 2;  // 区間数が多いときはブロックを大きくする
    }
    void fix_block(int b) {  // 空なら削除、そうでなければ末尾更新と分割
        if (bl_[b].empty()) {
            bl_.erase(bl_.begin() + b);
            last_.erase(last_.begin() + b);
            return;
        }
        last_[b] = bl_[b].back();
        if ((int)bl_[b].size() >= 2 * bsz_) split(b);
    }
    void rebalance() {
        std::vector<Itv> flat;
        flat.reserve(n_);
        for (const auto& v : bl_) flat.insert(flat.end(), v.begin(), v.end());
        bl_.clear();
        last_.clear();
        for (int s = 0; s < n_; s += bsz_) {
            const int e = std::min(n_, s + bsz_);
            bl_.emplace_back(flat.begin() + s, flat.begin() + e);
            last_.push_back(flat[e - 1]);
        }
    }
    // 要素列の [p, q) を e[0..k) で置き換える（p <= q）
    void replace(Pos p, Pos q, const Itv* e, int k) {
        if (bl_.empty()) {  // 空集合への挿入
            bl_.emplace_back(e, e + k);
            last_.push_back(e[k - 1]);
            n_ = k;
            for (int j = 0; j < k; ++j) total_ += e[j].r - e[j].l;
            return;
        }
        if (is_end(p)) p = q = Pos{nb() - 1, (int)bl_.back().size()};
        if (q.i == 0 && q.b > p.b) q = Pos{q.b - 1, (int)bl_[q.b - 1].size()};
        if (p.b == q.b) {
            std::vector<Itv>& v = bl_[p.b];
            const int cnt = q.i - p.i;
            for (int j = p.i; j < q.i; ++j) total_ -= v[j].r - v[j].l;
            if (k <= cnt) {
                std::copy(e, e + k, v.begin() + p.i);
                v.erase(v.begin() + p.i + k, v.begin() + q.i);
            } else {
                std::copy(e, e + cnt, v.begin() + p.i);
                v.insert(v.begin() + q.i, e + cnt, e + k);
            }
            n_ += k - cnt;
            fix_block(p.b);
        } else {
            std::vector<Itv>& vp = bl_[p.b];
            std::vector<Itv>& vq = bl_[q.b];
            for (int j = p.i; j < (int)vp.size(); ++j) total_ -= vp[j].r - vp[j].l;
            for (int b = p.b + 1; b < q.b; ++b) {
                for (const Itv& t : bl_[b]) total_ -= t.r - t.l;
                n_ -= (int)bl_[b].size();
            }
            for (int j = 0; j < q.i; ++j) total_ -= vq[j].r - vq[j].l;
            n_ += k - ((int)vp.size() - p.i) - q.i;
            vp.resize(p.i);
            vp.insert(vp.end(), e, e + k);
            vq.erase(vq.begin(), vq.begin() + q.i);
            bl_.erase(bl_.begin() + p.b + 1, bl_.begin() + q.b);
            last_.erase(last_.begin() + p.b + 1, last_.begin() + q.b);
            fix_block(p.b + 1);
            fix_block(p.b);
        }
        for (int j = 0; j < k; ++j) total_ += e[j].r - e[j].l;  // 先に引いてから足す（途中でのオーバーフロー防止）
        if ((long long)nb() * bsz_ > 4LL * n_ + 4LL * bsz_) rebalance();  // 小さいブロックが増えすぎたら詰め直す
    }

public:
    // block: 平方分割の初期ブロック長（1 以上。通常は指定不要。テストで小さくして境界を突くため）
    explicit ItvSet(int block = 128) : bsz_(block) {}

    // ---------------- 更新 ----------------
    Itv add(long long l, long long r) {  // [l, r) を追加。結合後の区間を返す
        const Pos p = r_ge_pos(l);        // [l, r) と重なる／接する最初の区間
        if (is_end(p) || at(p).l > r) {
            const Itv t{l, r};
            replace(p, p, &t, 1);
            return t;
        }
        if (at(p).l <= l && r <= at(p).r) return at(p);  // 既に覆われている
        const Pos q = l_gt_pos(r);        // 結合対象の次
        const Itv t{std::min(l, at(p).l), std::max(r, at(prev(q)).r)};
        replace(p, q, &t, 1);
        return t;
    }
    Itv add(const Itv& t) { return add(t.l, t.r); }
    long long erase(long long l, long long r) {  // [l, r) を削除。削除された長さを返す
        const Pos p = r_gt_pos(l);
        if (is_end(p) || at(p).l >= r) return 0;
        const Pos q = l_ge_pos(r);
        const Itv first = at(p), lastv = at(prev(q));
        Itv e[2];
        int k = 0;
        if (first.l < l) e[k++] = Itv{first.l, l};
        if (lastv.r > r) e[k++] = Itv{r, lastv.r};
        const long long before = total_;
        replace(p, q, e, k);
        return before - total_;
    }
    long long erase(const Itv& t) { return erase(t.l, t.r); }
    void clear() { n_ = 0; total_ = 0; bl_.clear(); last_.clear(); }

    // ---------------- 情報 ----------------
    int size() const { return n_; }
    bool empty() const { return n_ == 0; }
    long long length() const { return total_; }
    std::vector<Itv> to_vector() const {
        std::vector<Itv> v;
        v.reserve(n_);
        for (const auto& b : bl_) v.insert(v.end(), b.begin(), b.end());
        return v;
    }

    // ---------------- 判定 ----------------
    bool contains(long long x) const {
        const Pos p = r_gt_pos(x);
        return !is_end(p) && at(p).l <= x;
    }
    Itv find(long long x) const {
        const Pos p = r_gt_pos(x);
        return (!is_end(p) && at(p).l <= x) ? at(p) : Itv{};
    }
    bool covers(long long l, long long r) const {
        const Pos p = r_gt_pos(l);
        return !is_end(p) && at(p).l <= l && r <= at(p).r;
    }
    bool covers(const Itv& t) const { return covers(t.l, t.r); }
    bool intersects(long long l, long long r) const {
        const Pos p = r_gt_pos(l);
        return !is_end(p) && at(p).l < r;
    }
    bool intersects(const Itv& t) const { return intersects(t.l, t.r); }
    long long next_free(long long x) const {  // x 以上で覆われていない最小値
        const Pos p = r_gt_pos(x);
        return (!is_end(p) && at(p).l <= x) ? at(p).r : x;
    }
    long long prev_free(long long x) const {  // x 以下で覆われていない最大値
        const Pos p = r_gt_pos(x);
        return (!is_end(p) && at(p).l <= x) ? at(p).l - 1 : x;
    }
};

namespace itv2_test {

struct Naive {  // 正規化済み（重ならず隣接しない・昇順）の区間列を O(n) で愚直に管理
    std::vector<Itv> v;
    Itv add(long long l, long long r) {
        long long nl = l, nr = r;
        std::vector<Itv> w;
        for (const Itv& t : v) {
            if (t.r < l || r < t.l) w.push_back(t);
            else { nl = std::min(nl, t.l); nr = std::max(nr, t.r); }
        }
        const Itv m{nl, nr};
        w.insert(std::upper_bound(w.begin(), w.end(), m), m);
        v.swap(w);
        return m;
    }
    long long erase(long long l, long long r) {
        long long removed = 0;
        std::vector<Itv> w;
        for (const Itv& t : v) {
            if (t.r <= l || r <= t.l) { w.push_back(t); continue; }
            removed += std::min(t.r, r) - std::max(t.l, l);
            if (t.l < l) w.push_back(Itv{t.l, l});
            if (r < t.r) w.push_back(Itv{r, t.r});
        }
        v.swap(w);
        return removed;
    }
    Itv find(long long x) const {
        for (const Itv& t : v) if (t.l <= x && x < t.r) return t;
        return Itv{};
    }
    long long length() const {
        long long s = 0;
        for (const Itv& t : v) s += t.r - t.l;
        return s;
    }
};

[[noreturn]] static void fail(const std::string& what, long long seed, int step, long long x, long long y, long long expect, long long got) {
    std::cout << "\n*** MISMATCH *** " << what << " seed=" << seed << " step=" << step << " x=" << x << " y=" << y
              << " expect=" << expect << " got=" << got << std::endl;
    std::exit(1);
}
[[noreturn]] static void fail_itv(const std::string& what, long long seed, int step, long long x, long long y, const Itv& expect, const Itv& got) {
    std::cout << "\n*** MISMATCH *** " << what << " seed=" << seed << " step=" << step << " x=" << x << " y=" << y
              << " expect=" << expect << " got=" << got << std::endl;
    std::exit(1);
}

struct Config {
    const char* name;
    int block;
    long long lo, hi;   // 左端の範囲
    long long maxlen;   // 追加区間の長さの最大
    long long maxdel;   // 削除区間の長さの最大
    int ops;
    bool use_paint;     // 点ごとの塗り配列でも照合する（座標が小さいとき）
    int phase;          // 増える局面と減る局面を切り替える間隔
    int align_del;      // 削除のうち既存区間の端に合わせる割合（%）
    int reps;           // 繰り返し回数（シードを変える）
};

static void run(const Config& cfg, long long seed) {
    std::mt19937_64 rng((unsigned long long)seed * 0x9E3779B97F4A7C15ULL + 777);
    auto rnd = [&](long long a, long long b) { return a + (long long)(rng() % (unsigned long long)(b - a + 1)); };
    auto rlen = [&](long long mx) { return 1 + (rng() % 3 == 0 ? rnd(0, mx - 1) : rnd(0, std::min(mx, 4LL) - 1)); };
    ItvSet s(cfg.block);
    Naive nv;
    const long long P0 = cfg.lo - 2 * std::max(cfg.maxlen, cfg.maxdel) - 2;  // 座標の範囲 [P0, P1)（塗り配列もこの範囲）
    const long long P1 = cfg.hi + 2 * std::max(cfg.maxlen, cfg.maxdel) + 3;
    auto clamp = [&](long long& l, long long& r) {  // 生成した区間を範囲内に収める（空になったら false）
        l = std::max(l, P0);
        r = std::min(r, P1);
        return l < r;
    };
    std::vector<char> paint(cfg.use_paint ? (size_t)(P1 - P0) : 0, 0);
    int add_bias = 55;

    auto gen_x = [&]() {
        if (!nv.v.empty() && rng() % 2) {
            const Itv& t = nv.v[rng() % nv.v.size()];
            switch (rng() % 4) {
                case 0: return t.l;
                case 1: return t.r;
                case 2: return t.l - 1;
                default: return t.r - 1;
            }
        }
        return rnd(cfg.lo - 1, cfg.hi + std::min(cfg.maxlen, LLONG_MAX / 4) + 1);
    };

    for (int step = 0; step < cfg.ops; ++step) {
        if (step % cfg.phase == 0) add_bias = (step / cfg.phase) % 2 == 0 ? (int)rnd(60, 85) : (int)rnd(10, 35);  // 増える局面と減る局面
        const int r100 = (int)(rng() % 100);
        if (r100 < add_bias) {
            long long l, r;
            if (!nv.v.empty() && rng() % 4 == 0) {  // 既存区間の端にぴったり接する追加
                const Itv& t = nv.v[rng() % nv.v.size()];
                if (rng() % 2) { r = t.l; l = r - rlen(cfg.maxlen); } else { l = t.r; r = l + rlen(cfg.maxlen); }
            } else {
                l = rnd(cfg.lo, cfg.hi);
                r = l + rlen(cfg.maxlen);
            }
            if (!clamp(l, r)) continue;
            const Itv e = nv.add(l, r);
            const Itv g = (rng() % 2) ? s.add(l, r) : s.add(Itv{l, r});
            if (!(e == g)) fail_itv("add(return)", seed, step, l, r, e, g);
            if (cfg.use_paint) for (long long x = l; x < r; ++x) paint[(size_t)(x - P0)] = 1;
        } else if (r100 < 97) {
            long long l, r;
            if (!nv.v.empty() && (int)(rng() % 100) < cfg.align_del) {  // 既存区間の端に合わせた削除
                const Itv& t = nv.v[rng() % nv.v.size()];
                switch (rng() % 4) {
                    case 0: l = t.l; r = t.r; break;
                    case 1: l = t.l; r = l + rlen(cfg.maxdel); break;
                    case 2: r = t.r; l = r - rlen(cfg.maxdel); break;
                    default: l = t.l - rlen(cfg.maxdel); r = t.r + rlen(cfg.maxdel); break;
                }
            } else {
                l = rnd(cfg.lo, cfg.hi);
                r = l + rlen(cfg.maxdel);
            }
            if (!clamp(l, r)) continue;
            const long long e = nv.erase(l, r);
            const long long g = (rng() % 2) ? s.erase(l, r) : s.erase(Itv{l, r});
            if (e != g) fail("erase(return)", seed, step, l, r, e, g);
            if (cfg.use_paint) {
                long long pe = 0;
                for (long long x = l; x < r; ++x) { pe += paint[(size_t)(x - P0)]; paint[(size_t)(x - P0)] = 0; }
                if (pe != e) fail("paint-vs-naive erase", seed, step, l, r, pe, e);
            }
        } else if (r100 == 99 && rng() % 50 == 0) {
            s.clear();
            nv.v.clear();
            std::fill(paint.begin(), paint.end(), 0);
        }

        // ---------------- 全体の整合（size / length は毎回、全列挙はたまに） ----------------
        if ((long long)s.size() != (long long)nv.v.size()) fail("size", seed, step, 0, 0, (long long)nv.v.size(), s.size());
        if (s.empty() != nv.v.empty()) fail("empty", seed, step, 0, 0, nv.v.empty(), s.empty());
        if (step % 16 == 0 || cfg.use_paint) {
            if (s.length() != nv.length()) fail("length", seed, step, 0, 0, nv.length(), s.length());
        }
        if (rng() % 32 == 0) {
            const std::vector<Itv> got = s.to_vector();
            if (got != nv.v) fail("to_vector", seed, step, 0, 0, (long long)nv.v.size(), (long long)got.size());
            if (cfg.use_paint) {  // 塗り配列から区間列を作って愚直実装とも照合
                std::vector<Itv> pv;
                for (long long x = P0; x < P1; ++x) {
                    if (!paint[(size_t)(x - P0)]) continue;
                    long long y = x;
                    while (y < P1 && paint[(size_t)(y - P0)]) ++y;
                    pv.push_back(Itv{x, y});
                    x = y;
                }
                if (pv != nv.v) fail("paint-vs-naive intervals", seed, step, 0, 0, (long long)pv.size(), (long long)nv.v.size());
            }
        }

        // ---------------- クエリ ----------------
        const int nq = 1 + (int)(rng() % 3);
        for (int q = 0; q < nq; ++q) {
            const long long x = gen_x();
            long long a = gen_x(), b = gen_x();
            if (a > b) std::swap(a, b);
            if (a == b) ++b;
            if (rng() % 3 == 0) b = a + rlen(4);
            switch (rng() % 6) {
                case 0: {
                    const Itv e = nv.find(x);
                    const Itv g = s.find(x);
                    if (!(e == g)) fail_itv("find", seed, step, x, 0, e, g);
                    if (s.contains(x) != !e.empty()) fail("contains", seed, step, x, 0, !e.empty(), s.contains(x));
                    break;
                }
                case 1: {
                    bool e = false;
                    for (const Itv& t : nv.v) e |= (t.l <= a && b <= t.r);
                    const bool g = (rng() % 2) ? s.covers(a, b) : s.covers(Itv{a, b});
                    if (e != g) fail("covers", seed, step, a, b, e, g);
                    break;
                }
                case 2: {
                    bool e = false;
                    for (const Itv& t : nv.v) e |= (t.l < b && a < t.r);
                    const bool g = (rng() % 2) ? s.intersects(a, b) : s.intersects(Itv{a, b});
                    if (e != g) fail("intersects", seed, step, a, b, e, g);
                    break;
                }
                case 3: {
                    long long y = x;
                    for (Itv t = nv.find(y); t; t = nv.find(y)) y = t.r;
                    if (s.next_free(x) != y) fail("next_free", seed, step, x, 0, y, s.next_free(x));
                    break;
                }
                case 4: {
                    long long y = x;
                    for (Itv t = nv.find(y); t; t = nv.find(y)) y = t.l - 1;
                    if (s.prev_free(x) != y) fail("prev_free", seed, step, x, 0, y, s.prev_free(x));
                    break;
                }
                default:
                    if (cfg.use_paint && x >= P0 && x < P1) {
                        const bool e = paint[(size_t)(x - P0)] != 0;
                        if (s.contains(x) != e) fail("contains(paint)", seed, step, x, 0, e, s.contains(x));
                    }
                    break;
            }
        }
    }
}

inline void random_test() {
    const auto t0 = std::chrono::steady_clock::now();
    const Config cfgs[] = {
        // name                       block  lo     hi       maxlen  maxdel  ops    paint  phase  align_del  reps
        {"tiny block, dense", 1, 0, 30, 6, 5, 30000, true, 3000, 33, 3},
        {"block=2, dense", 2, 0, 60, 10, 8, 30000, true, 3000, 33, 3},
        {"block=3, mid", 3, -200, 200, 40, 20, 40000, true, 5000, 33, 3},
        {"block=4, long ranges", 4, 0, 400, 150, 150, 30000, true, 5000, 33, 3},
        {"block=8, grow/shrink", 8, 0, 4000, 2, 2, 50000, true, 5000, 90, 3},
        {"block=16, grow/shrink", 16, 0, 8000, 3, 2, 50000, true, 8000, 90, 3},
        {"default block, many itvs", 128, 0, 20000, 6, 4, 60000, true, 15000, 50, 2},
        {"default block, mixed lengths", 128, 0, 1000000, 3000, 2000, 60000, false, 10000, 40, 2},
        {"huge coords", 3, -2000000000000000000LL, 2000000000000000000LL, 1000000000000000000LL, 500000000000000000LL, 30000, false, 5000, 33, 3},
        {"huge coords default", 128, -2000000000000000000LL, 2000000000000000000LL, 100000000000000LL, 100000000000000LL, 30000, false, 7500, 50, 2},
    };
    long long seed = 1;
    for (const Config& c : cfgs) {
        for (int rep = 0; rep < c.reps; ++rep) run(c, seed++);
        std::cout << "  [OK] " << c.name << " x" << c.reps << "\n";
    }
    const double ms = std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - t0).count();
    std::cout << "random_test: ALL PASSED (" << (long long)ms << " ms)\n";
}

inline void demo() {
    using std::cout;
    auto S = [](const Itv& t) { return t ? "[" + std::to_string(t.l) + ", " + std::to_string(t.r) + ")" : std::string("none"); };
    auto B01 = [](bool v) { return std::string(v ? "1" : "0"); };
    auto V = [&](const std::vector<Itv>& v) { std::string r; for (const Itv& t : v) r += " " + S(t); return r; };
    // 1 行 =「呼び出し = 結果」＋「何を返す／何をするか」
    auto line = [](std::string left, const std::string& what) {
        if (left.size() < 36) left.resize(36, ' ');
        cout << left << " : " << what << "\n";
    };
    cout << "===== (2) ItvSet demo =====\n";
    cout << "重なる区間・接する区間を常に結合して持つ集合。該当なしのときは none（空区間 Itv{}）が返る\n";

    ItvSet s;
    cout << "\n[追加]  add は区間を追加して結合し、結合後の区間を返す\n";
    line("add(1, 3) -> " + S(s.add(1, 3)), "[1, 3) を追加。追加した区間を含む結合後の区間を返す");         // [1, 3)
    line("add(5, 7) -> " + S(s.add(5, 7)), "[5, 7) を追加（離れているので別の区間になる）");                // [5, 7)
    line("add(3, 5) -> " + S(s.add(3, 5)), "[3, 5) を追加。接する [1, 3) と [5, 7) が結合されて1つになる");  // [1, 7)
    line("add({10, 15}) -> " + S(s.add(Itv{10, 15})), "Itv でも渡せる");                                     // [10, 15)
    line("add(12, 13) -> " + S(s.add(12, 13)), "既に覆われているので何も変わらず、覆っている区間を返す");  // [10, 15)

    cout << "\n[情報]\n";
    line("size = " + std::to_string(s.size()), "区間の個数（結合後の個数）");                               // 2
    line("length = " + std::to_string(s.length()), "覆われている長さの合計");                              // 11
    line("empty = " + B01(s.empty()), "空かどうか（1: 空 / 0: 空でない）");                                 // 0
    line("to_vector =" + V(s.to_vector()), "全区間を昇順に並べた vector<Itv>（重ならず隣接もしない）");      // [1, 7) [10, 15)

    // ---- 判定 ----
    cout << "\n[判定]\n";
    line("contains(6) = " + B01(s.contains(6)), "6 を含む区間があるか（1: ある / 0: ない）");               // 1
    line("contains(7) = " + B01(s.contains(7)), "7 を含む区間があるか（[1, 7) は 7 を含まない）");          // 0
    line("find(12) = " + S(s.find(12)), "12 を含む区間");                                                    // [10, 15)
    line("find(8) = " + S(s.find(8)), "8 を含む区間は無いので none");                                        // none
    if (auto t = s.find(4))
        line("find(4): l = " + std::to_string(t.l) + ", r = " + std::to_string(t.r),
             "if (auto t = s.find(x)) で見つかった区間を受け取れる");                                          // find(4): l = 1, r = 7
    line("covers(2, 7) = " + B01(s.covers(2, 7)), "[2, 7) 全体が覆われているか");                          // 1
    line("covers({6, 11}) = " + B01(s.covers(Itv{6, 11})), "[6, 11) 全体が覆われているか（7, 8, 9 が空いている）");  // 0
    line("intersects(7, 10) = " + B01(s.intersects(7, 10)), "[7, 10) と共通部分を持つ区間があるか（重複判定）");  // 0
    line("intersects({6, 11}) = " + B01(s.intersects(Itv{6, 11})), "[6, 11) と共通部分を持つ区間があるか");  // 1
    line("next_free(0) = " + std::to_string(s.next_free(0)), "0 以上で覆われていない最小の値（= mex）");    // 0
    line("next_free(3) = " + std::to_string(s.next_free(3)), "3 以上で覆われていない最小の値");             // 7
    line("prev_free(12) = " + std::to_string(s.prev_free(12)), "12 以下で覆われていない最大の値");          // 9
    line("prev_free(8) = " + std::to_string(s.prev_free(8)), "8 以下で覆われていない最大の値（8 自身が空き）");  // 8

    // ---- 削除（区間は切断される） ----
    cout << "\n[削除]  erase は [l, r) の部分を削除し、削除された長さを返す\n";
    const long long d1 = s.erase(3, 11);                                                // [3,7) の 4 と [10,11) の 1
    line("erase(3, 11) -> removed " + std::to_string(d1), "[3, 11) を削除。[3, 7) の 4 と [10, 11) の 1 が消える");  // removed 5
    line("to_vector =" + V(s.to_vector()), "削除後の区間（はみ出した部分は残る）");                         // [1, 3) [11, 15)
    const long long d2 = s.erase(Itv{12, 13});                                          // 真ん中を削除すると2つに分かれる
    line("erase({12, 13}) -> removed " + std::to_string(d2), "区間の真ん中を削除すると2つに分かれる");     // removed 1
    line("size = " + std::to_string(s.size()), "区間の個数（[1, 3) [11, 12) [13, 15)）");                   // 3
    line("length = " + std::to_string(s.length()), "覆われている長さの合計");                              // 5
    const long long d3 = s.erase(100, 200);                                             // 何も無い所
    line("erase(100, 200) -> removed " + std::to_string(d3), "何も無い所を削除しても何も起きず 0 を返す"); // removed 0

    s.clear();
    cout << "\n[全削除]\n";
    line("after clear: size = " + std::to_string(s.size()), "clear() で全区間を削除した後の個数");         // 0
    line("length = " + std::to_string(s.length()), "長さの合計も 0");                                     // 0
}
