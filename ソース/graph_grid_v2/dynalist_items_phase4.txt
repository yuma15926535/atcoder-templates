△ 木DP（根付き木の DP の型）
	型
		RootedTree T(G, 0);
		for (int k = T.n - 1; k >= 0; --k) { int v = T.order[k]; dp[v] = 初期値; for (int c : T.children(v)) dp[v] = 合わせる(dp[v], dp[c]); }
	メモ
		05_rooted_tree を使う（order は行きがけ順なので、逆順に回すと子が先に終わる）
		部分木の和・最大は T.subtree_sum / T.subtree_fold、全頂点を根にするなら 05_rerooting
