00_graph_base（グラフ基盤：Graph・入力・変換・探索の結果 SearchResult）
	説明
		Graph G(n) / G.add_edge(u, v, w = 1)（有向）/ G.add_undirected(u, v, w = 1) / G.add(u, v, w, DIRECTED or UNDIRECTED) → 辺番号
		for (auto& e : G[v]) { e.to; e.w; e.id; } / G.es[id] = {from, to, w} / G.size() / G.edge_count()
		read_undirected(N, M) / read_directed(N, M) / read_undirected_w / read_directed_w / read_tree(N) / read_tree_w(N) / read_parents(N)（最後の引数 base は既定 1）
		graph_from_adj(adj)（vector<vector<int>> / vector<vector<pair<int, W>>>）/ graph_from_edges(n, us, vs, [ws,] UNDIRECTED, base) / graph_from_parents(par, [w,] base)
		G.reversed() / G.sort_adj() / G.in_degrees() / G.out_degrees() / G.add_vertex() / G.adj_list() / G.adj_list_w()
		SearchResult r：r.dist[v] / r.par[v] / r.reached(v) / r.path(t) / r.nearest_source() / auto [dist, par] = bfs(G, s);
		parent_edges(G, r) / path_edges(G, r, t) / restore_path(par, t) / IntSpan（children などが返す参照）
	メモ
		第二世代のグラフ系テンプレートはすべてこれを同梱済み。単独で貼るのは、自分で探索を書くときだけ
		Cost = long long、到達不能は DIST_INF = 1LL << 60（Main_base の LINF と同じ値）。頂点・辺番号の「なし」は -1
		辺に追加の情報があるときは、別の配列を辺番号 e.id で引く
